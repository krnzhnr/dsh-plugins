# Исправления русского перевода DSH

Бандл правит официальный русский перевод DeepSeek Harness по месту.
Полную локализацию (словари на ~2600 ключей) упразднили: русский теперь
встроен в ядро (`dsh-client-ui-conversation`, `dsh-client-ui-chat` и др.),
а повторный `locale.register(ns, 'ru', …)` ядро отклоняет исключением —
полные словари всё равно не применялись бы.

## Что правит

67 ключей в четырнадцати неймспейсах: `conversation`, `chat`, `cordis`,
`goal`, `plan`, `trajectory`, `forgePanel`, `deliverables`, `shortcuts`,
`settings.permission`, `model`, `job`, `workspace`, `schedule.catalog`.

- имена инструментов латиницей, как в оригинале: `Bash`, `Pwsh`, `Grep`,
  `Glob` (в официалах — `Баш`, `Пшш`, `Греп`, `Глоб`);
- смысловые ошибки: `queryRuntime` («Время выполнения запроса» →
  «Запросить рантайм»), `interruptAgent` («Агент прерываний» →
  «Прервать агента»), `signalTerminal` («Сигнальный терминал» →
  «Послать сигнал терминалу»), `lsp`, `hoverSymbol`;
- единообразие: везде инфинитив («Проверить плагины», «Запустить плагин
  Cordis», «Найти ссылки»), термин «командная задача», термин «задача»,
  `List-*` → «Список …»;
- статусы завершения `message.stepProcess.done.*` — активное прошедшее время
  («Записал файлы», «Обновил план») вместо дублей прогресса
  («Чтение файлов») и кривых причастий («Искомый код»,
  «Задаваемые вопросы»);
- `message.think` («Подумайте» → «Думаю»);
- заголовок списка задач `todo.title` («Дела» → «Задачи», единый термин);
- грубые ляпы: `cordis/action.run` («Беги» → «Запустить»),
  `goal/action.clear` («Четкая цель» → «Очистить цель»),
  `plan/preview.open` («Открытая планировка» → «Открыть план»),
  `trajectory/toolbar.search` («Траектория поиска» → «Поиск по траектории»),
  `model/trigger.ariaEffort` («аргументацию» → «уровень рассуждений»);
- фамильярное «ты» (`forgePanel`: «Создай» → «Создать»);
- термин «провайдер» вместо «поставщик», «задача» вместо «задание»,
  инфинитив в меню (`workspace`: «Архив сеанса» → «Архивировать сеанс»);
- недостающие ключи `hint.plan`/`placeholder.plan` (есть только в `ja`,
  без правки виден сырой ключ).

Стиль — как у официалов и английского оригинала: заголовки действий
отвечают на вопрос «Что сделать? / Что?».

## Как это устроено

Client-половина (`client.js`) в `apply()` через `ctx.effect`:

1. берёт живые словари ядра `ctx.locale.dicts.get(ns).get('ru')`;
2. накатывает правки через `Object.assign` (lookup читает словарь при
   каждом `translate`, новые строки сразу с правками);
3. подписывается на `locale.subscribe`, чтобы переприменить правки после
   перерегистрации словарей ядром (HMR);
4. один раз дёргает `publish` (если доступен в рантайме), чтобы уже
   видимые строки перечитали словари.

Оригиналы сохраняются и возвращаются при выгрузке бандла. `addLanguage`
не вызывается — язык `ru` уже регистрирует само ядро.

## Добавление новых правок

Дописать пару «ключ → значение» в `OVERRIDES` нужного неймспейса
в `client.js`. Ключ и официальное значение искать в ядре:
`resources/app.asar → dsh/node_modules/@deepseek-ai/dsh-client-ui-*/lib/client.js`.
