# Русский язык интерфейса DSH

Бандл добавляет в DeepSeek Harness язык «Русский»:

- новый пункт в селекторе языка (Настройки → Язык);
- русские строки для всех разделов интерфейса (~2600 ключей, 59 неймспейсов);
- fallback — английский: непереведённые ключи показывают английский текст.

## Установка

1. Установите бандл в профиль (профиль `desktop`):
   `plugin_manager → install_bundle → <папка dsh-locale-ru>`.
2. Откройте Настройки → Язык и выберите «Русский». Выбор сохраняется.

## Как это устроено

Client-половина (`client.js`) в `apply()`:

1. `ctx.locale.addLanguage({ id: 'ru', label: 'Русский', fallback: 'en' })`;
2. для каждого неймспейса `ctx.locale.register(ns, 'ru', dict)`.

Регистрация идёт через `ctx.effect`, поэтому выгрузка бандла возвращает английский.

## Обновление словарей

Словари собраны дампом текущих en-строк (см. `../locale-dump`, временный бандл).
После обновления DSH новые ключи покажут английский текст, пока их не переведут:
перезапустите дамп, допереведите `extracted/*.en.json` и пересоберите `client.js`.
