# Русский исправленный для DSH

Бандл добавляет отдельный язык «Русский исправленный» (`ru-fixed`):
полные русские словари (59 неймспейсов, ~2620 ключей) голосом
«Что делаю?» / «Что сделал?» плюс 30 фиксов. Официальный «Русский»
не трогается. Чего нет у нас (новые ключи свежих версий DSH), закрывает
fallback-цепочка `ru-fixed` → `ru` → `en`.

## Установка

1. Установите бандл в профиль.
2. Откройте Настройки → Язык и выберите «Русский исправленный».

## Как это устроено

Client-половина (`client.js`) в `apply()` через `ctx.effect` — форма
1-в-1 как исторический v1.0.5 (без `publish`, `subscribe` и доступа
к `locale.dicts`):

1. `ctx.locale.addLanguage({ id: 'ru-fixed', label: 'Русский исправленный',
   fallback: 'ru' })`, а если официального `ru` нет (старые ядра) —
   с `fallback: 'en'`;
2. для каждого неймспейса `locale.register(ns, 'ru-fixed', dict)`.

30 фиксов поверх словарей: завершение «Что сделал?» (14 `done.*`:
«Записал файлы»), прогресс от первого лица (14 `stepProcess.*`:
«Читаю файлы»), `subagent/mode.continuable` («можно продолжить»),
`conversation/todo.rowTitle` («Обновляю список задач»).

## Добавление новых правок

Правкой `client.js` напрямую (формат `"key": "value"` внутри нужного
неймспейса). Базовые словари — слепок en-строк DSH 0.2.1-rc.5
(см. `git show 0c6ebce:dsh-locale-ru/client.js`); поверх запечены 30 фиксов:
завершение «Что сделал?», прогресс от первого лица, `mode.continuable`,
`todo.rowTitle`.
