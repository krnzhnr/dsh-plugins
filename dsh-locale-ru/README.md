# Русский язык интерфейса DSH поверх официального

Бандл включает один русский язык и при включении подменяет официальные
строки своими: берутся наши полные словари (59 неймспейсов, ~2560 ключей),
поверх накатываются точечные слои. Чего у нас нет (новые ключи свежих
версий DSH) — закрывает официальный перевод и английский fallback.
Отдельного языка в селекторе нет — правится сам «Русский».

## Слои (порядок наката)

1. `RU_BASE` — наши полные словари голосом «Что делаю?» (59 неймспейсов),
   кроме протухшего: 4 заголовка расписаний и ключи про «напоминания» там,
   где оригинал уже говорит про задачи автоматизации. Новые ключи ядра
   при этом уцелевают.
2. `AUDIT` — точечные правки в 25 неймспейсах:
   - имена инструментов латиницей (`Bash`, `Pwsh`, `Grep`, `Glob`);
   - грубые ляпы: «Беги», «Четкая цель», «планировка», «Траектория поиска»,
     «аргументация», «по адресу», «Солнце», «Срок оплаты», «Клеммы»,
     «Вакансия», «Рулевое управление», «магистратура», «Пшш»;
   - фамильярное «ты» → вежливое «вы»;
   - термины: «провайдер», «задача», «участник команды», «промпт», «вывод»;
   - счётчики («Сессии {n}» → «{n} сессий»), падежи, порядок слов;
   - прогресс от первого лица («Читаю файлы»), завершение — «Что сделал?»
     («Записал файлы»).

Стиль — голос агента: заголовки действий отвечают на вопрос «Что делаю?»
(«Создаю цель», «Читаю»), живой прогресс — тоже («Читаю файлы»),
завершение — «Что сделал?» («Записал файлы»).

## Как это устроено

Client-половина (`client.js`) в `apply()` через `ctx.effect`:

1. для неймспейсов, знакомых ядру, правит живой словарь
   `ctx.locale.dicts.get(ns).get('ru')` по месту (повторный `register`
   ядро отклоняет, поэтому только так);
2. для неймспейсов без официального `ru` — регистрирует свой словарь
   через `locale.register` (как раньше);
3. подписывается на `locale.subscribe`, чтобы переприменить правки после
   перерегистраций ядра (HMR), включая случай «ядро подвезло словарь позже»;
4. один раз дёргает `publish` (если доступен), чтобы видимые строки
   перечитали словари.

Оригиналы сохраняются и возвращаются при выгрузке бандла.

## Добавление новых правок

Точечные — парой «ключ → значение» в `AUDIT` нужного неймспейса
в `client.js` (собирается скриптом из `rev-*.json`, см. историю).
Ключ и официальное значение искать в ядре:
`resources/app.asar → dsh/node_modules/@deepseek-ai/dsh-client-ui-*/lib/client.js`.
Полные словари правятся только откатом протухших ключей в `DROP`.
