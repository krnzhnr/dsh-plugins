# Установка Free Web Search (`@local/free-web-search` 1.1.0)

Это плагин-бандл для DeepSeek Harness: добавляет **бесплатный веб-поиск без
API-ключей** (7 резервных каналов) и **fetch-провайдер**, который работает через
прокси в режиме fake-IP. Инструменты остаются штатными `web_search` /
`web_fetch` — меняется только источник данных.

- Лицензия: MIT (см. `LICENSE`), без сторонних зависимостей и без телеметрии.
- Проверено на DSH `0.2.1-rc.5` (desktop, Windows).
- Работает в любом профиле, где есть `ctx.web` (обычный `desktop`/`web` профиль).

## Что изменится

Патч бандла переопределяет host-строку `web`:

```yaml
searchProvider: free-web      # цепочка бесплатных каналов
fetchProvider: http-fakeip    # fetch с исключением для fake-IP прокси
```

Это действует на все сессии профиля. Штатный провайдер `deepseek-official`
остаётся зарегистрированным, но не выбран — можно вернуться, удалив бандл.

## Шаг 1. Распаковать

Распакуйте архив в **постоянную папку** без пробелов в пути, например:

```
C:\Users\<вы>\dsh-plugins\dsh-free-web-search
```

Внутри этой папки должны лежать `package.json`, `index.js`, `cordis.patch.yml`
и остальные файлы плагина (а не ещё одна вложенная папка).

После установки профиль хранит **ссыпку на эту папку** — не перемещайте и не
удаляйте её, иначе плагин перестанет загружаться.

## Шаг 2. Установить

### Вариант A — попросить агента (рекомендуется)

Откройте новую сессию DSH и отправьте агенту:

> Установи локальный бандл плагина в текущий профиль:
> `plugin_manager` → `action: install_bundle`, target:
> `C:\Users\<вы>\dsh-plugins\dsh-free-web-search`.
> Если попросит подтверждение — разреши. После установки проверь, что
> `web_search` работает.

Агент вызовет `plugin_manager install_bundle`; успешный результат — ответ со
`"application": "applied"` и без `warnings`.

### Вариант B — через страницу Plugins

Откройте **Plugins** (левая панель) → установка бандла → укажите путь к
распакованной папке. Название в списке будет «Бесплатный веб-поиск» /
“Free Web Search”.

### Если `plugin_manager` недоступен

Значит, в вашем пресете агента нет этого инструмента. Тогда используйте
страницу Plugins либо другой пресет, где инструмент менеджера плагинов есть
(например, `cordis`/`standard` в стандартной поставке).

## Шаг 3. Проверить

1. Попросите агента: «Найди в интернете, что нового в DeepSeek Harness, дай
   ссылку на источник». В ответе должны быть источники и/или сводка.
2. Или попросите `.web_fetch https://example.com/` — должна вернуться страница.
3. Если поиск всё ещё идёт через старый провайдер (ошибка `401` от DeepSeek),
   перезапустите DSH и повторите.

Опционально (нужен Node.js 22+): проверка из папки плагина:

```powershell
node test/smoke.mjs
```

Ожидаемо: `23/23 passed`.

## Ограничения

- Каналы бесплатные, но **не безлимитные**: keyless-эндпоинты режут по IP,
  жёстких квот не публикуют. Короткие серии (десятки запросов) обычно проходят;
  при интенсивном использовании возможны `429`, тогда цепочка переходит на
  следующий канал, а упёршийся «остывает» 5 минут.
- `web_search`: 1–4 запроса за вызов, до 8 источников, бюджет 60 с.
- `web_fetch`: до 5 МБ / 100 тыс. символов, только same-origin редиректы,
  приватные/локальные адреса запрещены.
- Запросы уходят в Tavily/Exa/Parallel/TinyFish/DuckDuckGo/Bing; при желании
  можно добавить свой SearXNG (`searxngBaseURL`) — это единственный вариант
  без сторонней квоты.

## Обновление

1. Попросите агента: `plugin_manager` → `remove_bundle`, target
   `@local/free-web-search`.
2. Распакуйте новую версию в папку и установите её так же, как в шаге 2.
3. При замене уже установленного пакета DSH может потребовать перезапуск,
   чтобы подхватить новый JS-код.

## Удаление (откат)

- Через агента: `plugin_manager` → `remove_bundle`, target
  `@local/free-web-search`.
- Или страница Plugins → удалить бандл «Free Web Search».

После удаления вернутся штатные провайдеры: DeepSeek-поиск (нужен валидный
`DEEPSEEK_API_KEY`) и строгий public-IP-only fetch.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `already-installed` | Сначала `remove_bundle`, затем `install_bundle` заново |
| Поиск отвечает `401` / ошибкой DeepSeek | Активирован старый провайдер: проверьте установку, перезапустите DSH |
| `configured web provider "free-web" is not registered` | Бандл не активировался: `list_bundles` должен показывать установленный/включённый `@local/free-web-search`; перезапустите DSH |
| Fetch пишет `non-public IP` | Плагин не активен (или `allowFakeIp: false`): перезапустите DSH |
| Другая версия DSH | Плагин использует только публичный seam `ctx.web`; если версия сильно новее/старее и строка `web` изменилась — напишите, подстрою патч |
