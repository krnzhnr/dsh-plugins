# Установка OpenCode Go Usage (`@local/opencode-go-usage`, v0.3.0)

Плагин для **DeepSeek Harness** (Web GUI): показывает расход подписки
**OpenCode Go** прямо в композере.

- Свёрнуто — маленькая пилюля рядом со встроенными метриками: колечко и окно,
  **ближайшее к своему лимиту**, с процентом (например `5h · 15%`).
- По клику — панель с деталями: процент и суммы `$израсходовано / $лимит`,
  строки по окнам **5 часов / неделя / месяц**, состояние подписки, таймер
  сброса и кнопка обновления.

## Что нужно

1. **DeepSeek Harness** с Web GUI (десктопное приложение или `dsh web`);
   профиль `desktop`/`web` — плагин состоит из host- и browser-части.
2. **OpenCode**, в котором выполнен вход в OpenCode Go (`/connect` →
   **OpenCode Go**). Ключ сохраняется в `auth.json` самого OpenCode.
3. Свой собственный аккаунт OpenCode Go. **В архиве нет ключей и данных
   аккаунта** — каждый использует свой.

## Шаг 1. Распакуйте

Распакуйте архив в **постоянную папку**, которую не будете перемещать:

- Windows: `C:\Users\<вы>\dsh-plugins\`
- macOS / Linux: `~/dsh-plugins/`

Должно получиться так (важно — без двойной вложенности):

```
C:\Users\<вы>\dsh-plugins\opencode-go-usage\package.json
C:\Users\<вы>\dsh-plugins\opencode-go-usage\index.js
...
```

После установки профиль DSH будет ссылаться на эту папку: не перемещайте и не
удаляйте её, иначе плагин перестанет загружаться. Путь без пробелов и
кириллицы надёжнее.

## Шаг 2. Установите в DSH

### Вариант A — попросить агента (рекомендуется)

Откройте сессию DSH и отправьте агенту:

> Установи локальный бандл плагина в текущий профиль:
> `plugin_manager` → `action: install_bundle`, target:
> `<ПОЛНЫЙ ПУТЬ К ПАПКЕ opencode-go-usage>`.
> Если попросит подтверждение — разреши. После установки проверь, что под
> полем ввода появилась пилюля OpenCode Go.

`target` — абсолютный путь до папки, в которой лежит `package.json`
(например `C:\Users\<вы>\dsh-plugins\opencode-go-usage`).

Успешный результат: ответ содержит `"application": "applied"` и не содержит
`warnings`.

### Вариант B — через страницу Plugins

**Plugins** (левая панель) → установка бандла → укажите путь к распакованной
папке `opencode-go-usage`. В списке появится название **OpenCode Go Usage**.

### Если `plugin_manager` недоступен

В вашем пресете агента нет этого инструмента. Используйте страницу Plugins или
пресет, где менеджер плагинов есть (например `cordis` / `standard`).

## Шаг 3. Обновите страницу

Перезагрузите Web GUI: **Ctrl+R** (Windows/Linux) или **Cmd+R** (macOS).
Пилюля появляется в строке под карточкой ввода — рядом со встроенными
пилюлями активности и токенов — когда открыта сессия.

Если после установки плагин не виден, перезапустите DSH: обновление
клиентского JS может требовать нового запуска.

## Проверка

1. Под полем ввода есть пилюля вида `5h · 15%` (окно может быть `week` или
   `month` — плагин показывает ближайшее к лимиту).
2. Нажмите на пилюлю — откроется панель с суммами и таймерами сброса.
3. `↻` в панели — принудительное обновление; обычное автообновление — раз в
   минуту.

## Настройка (необязательно)

В `cordis.patch.yml` внутри папки плагина:

```yaml
config:
  refreshSeconds: 300   # кэш успешного чтения, 30..3600 секунд
  timeoutMs: 15000      # таймаут запроса, 1000..60000 мс
  # authFile: C:\Users\me\.local\share\opencode\auth.json
  # providerKey: opencode-go
  # apiBase: https://opencode.ai
```

Плагин сам ищет `auth.json` OpenCode в стандартных местах Windows/macOS/Linux
(`~/.local/share/opencode/auth.json`, `%APPDATA%`, `%LOCALAPPDATA%`,
`~/Library/Application Support/opencode`, `~/.config/opencode`). Если файл лежит
иначе — задайте `authFile`. Ключ также можно передать переменной окружения
`OPENCODE_GO_API_KEY` для процесса DSH.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Пилюли нет после установки | Обновите страницу; проверьте `plugin_manager` → `list_bundles`: `@local/opencode-go-usage` должен быть `installed`/`enabled`; перезапустите DSH |
| «No OpenCode Go key found» | Войдите в OpenCode Go в OpenCode (`/connect`) или укажите `authFile` в конфиге плагина |
| «OpenCode rejected the API key» | Ключ отозван/просрочен — переподключите OpenCode Go и повторите |
| «Console is unreachable / timed out» | Нет сети/прокси; плагин повторяет автоматически |
| `already-installed` при установке | Сначала `plugin_manager` → `remove_bundle` target `@local/opencode-go-usage`, затем установите заново |
| Ошибка `SyntaxError` при установке | Файл `package.json` повреждён (BOM/кодировка) — распакуйте архив заново |
| Ничего не помогло | Пришлите версию DSH, тип профиля (`desktop`/`web`), текст ошибки из консоли браузера (F12) и вывод `plugin_manager list_bundles` |

## Приватность

- Ключ читается **только на хосте** из `auth.json` OpenCode; браузер получает
  лишь суммы, проценты и даты (и замаскированный префикс ключа).
- Сеть: только `https://opencode.ai` (консоль OpenCode). Телеметрии и
  сторонних серверов нет, файлы не изменяются.
- В архиве нет ключей, cookie и личных данных.

## Удаление

`plugin_manager` → `remove_bundle`, target `@local/opencode-go-usage`.
Или страница Plugins → удалить бандл **OpenCode Go Usage**. После удаления
пилюля исчезнет.

## Состав архива

```
opencode-go-usage/
  package.json          манифест бандла (name, dsh.bundle.patch, dsh.client)
  cordis.patch.yml      слой загрузчика: вставляет host-плагин и конфиг
  index.js              host-часть: ключ OpenCode, запрос к консоли, кэш, маршрут
  client.js             browser-часть: пилюля и панель в композере
  locale/en.json        название/описание для страницы Plugins
  locale/ru.json
  icon.svg              иконка плагина
  README.md             краткое описание (English)
  INSTALL.md            этот файл
  LICENSE               MIT
  test/                 необязательные тесты для проверки (node)
INSTALL-FIRST.txt       краткая памятка (этот же порядок действий)
```

## Лицензия

MIT — см. `LICENSE`. Плагин использует внутренний эндпоинт консоли OpenCode
(`/console/api/go/status`); публичного API у OpenCode Go пока нет, поэтому
формат ответа может измениться после обновления OpenCode. При поломке плагин
покажет ошибку, а не молча неверные числа.
